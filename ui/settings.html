      Mode

      How to mute Discord

      In Discord: User Settings › Keybinds › Add a Keybind, and choose the action below. Then click “Send the shortcut” here and, within 5 seconds, click Discord's keybind field: the application types the shortcut for you.

      Shortcut:
      Press the shortcut, then release it… Escape cancels.

      F13 to F24 are keys no game uses: sending them has no effect in the game.

      On Linux, Discord shortcuts only work in an X11 session. Under Wayland, use the Application method.

      Status:

      Discord only lets an application control your microphone if you created it yourself. It takes two minutes:

      1. Open the Discord Developer Portal and click “New Application”.

      2. Copy the Application ID (Client ID) from “General Information”.

      3. In “OAuth2”, reset and copy the Client Secret.

      4. In “OAuth2 › Redirects”, add the redirect URL below, then save.

      5. Paste the Client ID and Client Secret here, click “Check”, then “Save”.
